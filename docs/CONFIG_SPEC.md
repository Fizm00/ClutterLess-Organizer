# CONFIG_SPEC

Format: YAML. File: `config.yaml`. Generated by `organizer init`.

## 1. Full example

```yaml
version: 1

settings:
  stable_after_seconds: 3        # file size/mtime must be unchanged this long before moving (watch mode)
  ignore_ext: [crdownload, part, tmp, download, partial, opdownload]
  ignore_names: ["desktop.ini", "thumbs.db", ".DS_Store"]
  ignore_hidden: true
  conflict: rename               # only "rename" and "skip" are allowed. Never overwrite.
  fallback_dir: ""               # if non-empty, unmatched files go here; empty = leave in place

watch:
  - path: ~/Downloads
    recursive: false
  - path: ~/Desktop
    recursive: false

rules:
  - name: Images
    match:
      ext: [jpg, jpeg, png, gif, webp, bmp, svg]
    move_to: ~/Pictures/Sorted/{year}

  - name: Documents
    match:
      ext: [pdf, docx, doc, xlsx, xls, pptx, txt, md]
    move_to: ~/Documents/Inbox/{ext}

  - name: Invoices
    match:
      name_regex: "(?i)(invoice|faktur|receipt|kwitansi)"
    move_to: ~/Documents/Finance/{year}-{month}

  - name: Installers
    match:
      ext: [exe, msi, dmg, deb, pkg]
    move_to: ~/Downloads/_Installers

  - name: Archives
    match:
      ext: [zip, rar, 7z, tar, gz]
      min_size: 1MB
    move_to: ~/Downloads/_Archives

  - name: Old stuff
    match:
      older_than: 90d
    move_to: ~/Downloads/_Old
```

## 2. Fields

### Top level
| Field | Type | Required | Notes |
|---|---|---|---|
| `version` | int | yes | Must be `1` |
| `settings` | object | no | Defaults apply |
| `watch` | list | yes | At least one entry |
| `rules` | list | yes | Evaluated top to bottom, **first match wins** |

### `settings`
| Field | Default | Notes |
|---|---|---|
| `stable_after_seconds` | 3 | Min 1 |
| `ignore_ext` | list above | Case-insensitive, no leading dot |
| `ignore_names` | list above | Case-insensitive exact names |
| `ignore_hidden` | true | Dotfiles and Windows hidden attribute |
| `conflict` | `rename` | `rename` or `skip` |
| `fallback_dir` | empty | Optional catch-all |

### `watch[]`
| Field | Notes |
|---|---|
| `path` | Required. Supports `~`, env vars (`%USERPROFILE%`, `$HOME`) |
| `recursive` | Default false. When true, never descend into any rule's `move_to` destination (prevents loops) |

### `rules[]`
| Field | Notes |
|---|---|
| `name` | Required, unique |
| `match` | Required, at least one condition |
| `move_to` | Required. Template vars allowed |

### `match` conditions (all specified conditions must hold: AND)
| Key | Type | Semantics |
|---|---|---|
| `ext` | list of string | Case-insensitive, no dot. Matches final extension only |
| `name_glob` | list of string | `filepath.Match` style, case-insensitive on Windows |
| `name_regex` | string | Go RE2 syntax, tested against file name (not full path) |
| `min_size` / `max_size` | size string | `500KB`, `1MB`, `2GB` (1024-based) |
| `older_than` | duration string | `30d`, `12h`, `2w` (d, w, h supported) based on mtime |

## 3. Template variables in `move_to`

| Var | Meaning |
|---|---|
| `{year}` | 4-digit year of file mtime |
| `{month}` | 2-digit month of file mtime |
| `{day}` | 2-digit day |
| `{ext}` | lowercase extension, `noext` if none |
| `{name}` | file name without extension |

Unknown variables are a validation error.

## 4. Validation rules

- `version` must be `1`.
- Rule names unique and non-empty.
- Every rule has at least one match condition and a `move_to`.
- Regexes compile; sizes and durations parse.
- Warn if a `move_to` destination sits inside a watched folder that has `recursive: true` (the destination must be excluded from scanning to prevent loops).
- Errors must point at the rule name and field, e.g. `rules[2] "Invoices": invalid name_regex: ...`.

## 5. Behavior notes

- Matching always runs against lowercase-normalized extension.
- Files with ignored extension/name/hidden are skipped before rule evaluation.
- Directories inside a watched folder are never moved in v1 (files only).
- No rule matches and no `fallback_dir`: leave the file untouched, report as "unmatched" in `run` output.
