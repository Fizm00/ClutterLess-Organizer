# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | Yes                |

## Reporting a Vulnerability

If you discover a security vulnerability in ClutterLess Organizer (`cless`), please report it responsibly:

1. **Do not open a public issue.**
2. Send an email to the project maintainers with details, steps to reproduce, and any proof of concept.
3. You will receive an acknowledgment within 48 hours.
4. Maintainers will work on a fix and release an advisory once patched.

Thank you for helping keep ClutterLess Organizer safe for everyone.
